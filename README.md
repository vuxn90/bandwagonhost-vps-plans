### 流量配额和端口速率不是一回事

40G 方案每月提供 500 GB 流量，端口速率为 1.5 Gbps；1280G 方案每月提供 8 TB 流量，端口速率为 5 Gbps。

但“有备份”不代表可以完全不管数据。重要业务至少要确认：

- 备份是否覆盖应用数据和数据库；

个人博客和测试项目可以接受更简单的备份策略，订单、会员、财务或客户数据则不应只依赖 VPS 平台上的一份备份。
